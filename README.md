# Podcast facile

Un studio de podcast pédagogique dans le navigateur pour préparer une émission, enregistrer des voix, ajouter des musiques et bruitages, puis exporter le montage en MP3 ou WAV.

[Ouvrir Podcast facile](https://courscircuit.github.io/PodcastFacile/)

## Utilisation

Créez un projet, rédigez les parties de l’émission, autorisez le microphone pour enregistrer les voix, puis ajoutez sons et musiques avant l’export. Sauvegardez le projet `.podfacile` pour le reprendre. Lors de la publication d’un podcast, téléchargez et joignez les crédits proposés dans l’application.

## Développement

Avec Node.js : `npm ci` puis `npm run dev`. Pour construire le site : `npm run build`.
